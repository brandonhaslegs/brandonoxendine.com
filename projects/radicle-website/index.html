Radicle Website

Design and front end work on radicle.network, Radicle’s website, shipped as patches from February to May 2026: the Install and Learn pages, a mobile layout, the release and update listings, a How it works page and a home for Radicle CI.

Role: Visual Design, Copywriting, Website, Code

Jump to: Install, Learn, How it works, Mobile, Updates, Radicle CI

Radicle is a way to collaborate on code without a central server. The website is where most people meet it, so it has to explain a pretty unusual idea quickly and then get out of the way. The old site leaned hard on a retro terminal look. The new one is quieter: a left sidebar, big two tone headlines and dithered images that carry the personality.

Install

The Install page puts every way into Radicle side by side: the CLI, the desktop app, an agent for Pi and a skill for Claude Code. Each card gets a real screenshot or a mark, one line on who it’s for and a command you can copy. Copying now shows a checkmark, and every code snippet on the site shares the same style.

Learn

Learn collects everything you need to understand Radicle in one place: How it works, the guides and a glossary. I laid it out to share its cards with the Install page, gave the guides portrait images, shortened their descriptions and kept them in columns down to small screens.

How it works

The How it works page was a scrolling slide presentation that was hard to read and harder to link to. I turned it into a normal two column page with an illustration next to each idea.

I pulled the illustrations into their own component and gave each a small ambient animation. They switch off if you prefer reduced motion.

I also did a copy pass across the whole site (sentence case, clearer calls to action, and fewer em dashes), added staggered entrances when a page loads, and animated the sidebar sub navigation with CSS view transitions. Then I explored a Get started page, with a call to action in the header pointing to it.

My favorite exploration was a page about GitHub’s uptime. It charts GitHub’s own status page data since 2022, which adds up to more than 72 days of degraded or unavailable service. Radicle doesn’t have that problem, because there’s no server to go down.

Mobile

The site didn’t really work on phones. I made the sidebar collapse into a full screen menu with a big colored block for each section, fixed the scroll lock when you resize with the menu open, stacked the footer and tuned the spacing on the homepage, Install and Learn.

Releases and updates

Releases and blog posts were cards with emoji in the titles. I made them a plain list that shares one set of styles: a version or author line, a title, a date and a one line summary written for each release. Hovering one entry dims the rest.

Radicle CI

Radicle CI runs continuous integration on top of Radicle, but its docs were scattered. I designed a landing page for it, explaining the broker, adapters and the rad-ci extension, linking the guide and office hours, with the design documents as subpages. The Install page’s CI card points to it.
